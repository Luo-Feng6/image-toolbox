# 🖼️ 图片工具箱

当前版本：**V4.16（2026-07-25）**

纯浏览器端图片处理工具，**不上传任何数据到服务器**，所有处理均在本地完成。

## 🚀 两种使用方式

### 🟢 浏览器版（推荐）

双击 `index.html` 即可使用，无需安装任何软件。

### 🔵 桌面版

双击 `start.bat` 启动本地服务器，浏览器自动打开 `localhost:8765`。
桌面版额外支持：自选保存路径、静默批量保存。
关闭命令窗口即停止服务。

## ✨ 亮点

- **单文件** — 一个 `index.html`，5973 行，双击即用
- **零依赖** — 不加载任何框架或图标库（JSZip / heic2any 按需 CDN 加载）
- **纯本地** — Canvas API 处理，图片不离开浏览器
- **批量队列** — 支持流水线预设（压缩→滤镜→边框→水印，一键管道）
- **19 套主题** — 12 套亮色 + 7 套暗色 + 9 种强调色，可自动跟随系统
- **28 个社交平台** — 小红书/朋友圈/B站/微博等预设尺寸
- **预设系统** — 每个工具可保存/重命名预设，含说明字段
- **历史记录** — 自动记录处理历史，支持搜索和备注
- **快捷键** — Home/Backspace/1-5/?/Esc/Ctrl+V + 文字工具方向键
- **拖拽上传** — 支持文件/文件夹拖拽批量导入
- **移动端可用** — 模糊/像素化/标注支持触屏涂抹

## 🔧 技术栈

- 纯 HTML + CSS + JavaScript
- Canvas API 处理全部图片操作
- localStorage 持久化（设置/历史/预设/收藏）
- CSS 变量主题系统（13 个语义色 + 5 个 RGB 变量）
- 深色/浅色主题 + 自动跟随系统
