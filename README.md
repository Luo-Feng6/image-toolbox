# 🖼️ 图片工具箱

纯浏览器端图片处理工具，所有处理均在本地完成，**不上传任何数据到服务器**。

## 使用方式

双击 `index.html` 即可打开使用，无需安装任何软件。

## 功能列表

### V1（已完成）

| 工具 | 功能 |
|------|------|
| 🗜️ 图片压缩 | 4种模式（智能/质量优先/体积优先/自定义）、质量滑块、格式选择、尺寸缩放、悬停对比原图、EXIF清除 |
| 🔄 格式转换 | JPEG / PNG / WebP / AVIF / BMP 互转、透明背景填充 |
| ✂️ 图片裁剪 | 自由裁剪 + 固定比例（1:1/4:3/16:9/9:16）、拖拽调整选区、旋转翻转 |
| 📐 尺寸调整 | 百分比 / 像素 / 预设三种模式、锁定比例 |
| 🔃 旋转翻转 | 90°/180°/自定义角度、水平/垂直翻转、自动裁切留白 |
| 📦 批量处理 | 多图上传、统一参数、逐张/ZIP打包下载（需 JSZip CDN） |
| 🔣 转 Base64 | 图片转 Data URI 代码，可复制或下载 |

## 技术实现

- 纯 HTML + CSS + JavaScript，单文件，无构建工具
- Canvas API 处理所有图片操作
- 暗色/浅色主题切换，偏好自动保存
- 支持拖拽上传、点击上传、Ctrl+V 粘贴上传
- 响应式布局，手机也能用

## 外部依赖

- JSZip（CDN）：仅批量 ZIP 下载需要，首次加载后浏览器缓存

## 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+V | 粘贴剪贴板图片 |
| ← 返回 | 返回上一页 |

## 隐私说明

🔒 **所有图片处理均在浏览器本地完成，图片不会离开你的电脑。**
